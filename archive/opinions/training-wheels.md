# 보조바퀴 (가칭) · 장롱면허 탈출 코치

작성 winter1 · 2026-11-05 · 상태: **후보 정리, 팀 합의 전**. 평가 기준은 [judging-criteria.md](../../opinions/judging-criteria.md), 다른 후보는 [idea-brainstorm.md](idea-brainstorm.md), [drive-watch.md](drive-watch.md).

## 1. 문제 정의

### 1.1 규모와 시의성

- **초보는 훨씬 더 사고 난다**: 경력 1년 미만 운전자의 사고율은 경력 7년 이상의 **2.1배**(2015년, 현대해상 교통기후환경연구소 분석 보도). 첫해에 사고를 낸 운전자는 5년 뒤 사고율도 더 높다. 영국에서도 새 운전자 5명 중 1명이 1년 안에 사고를 낸다는 조사가 있다.
- **배우는 데 비싸다**: 도로연수는 10시간 기준 약 30~58만원(경찰청 인용 보도 평균 58만원, 방문연수 29만원~).
- **제도가 바뀌는 중**: 경찰청은 2025-12 학원 방문 의무를 없애고 원하는 장소에서 연수할 수 있게 법령을 고친다고 밝혔다. 연수가 "학원 밖, 내 생활 도로"로 나오는 흐름이다.
- 장롱면허 규모는 공식 통계를 찾지 못했다 → 면허 보유자 대비 실제 운전자 비율을 TAAS·경찰청 자료로 확인 필요.

수치는 기사 보도 기준이며 연도가 오래된 것도 있다. 기획서에는 원자료로 교체한다.

### 1.2 한 문장으로

> 초보·장롱면허 운전자가 무서워하는 것은 운전 전체가 아니라 **합류·비보호 좌회전·후진 주차 같은 특정 순간**인데, 도로연수가 끝나면 그 순간을 **혼자 연습할 방법도, 내가 늘고 있는지 알 방법도 없다.**

### 1.3 세 가지 구체적 문제

| | 문제 | 지금 실제로 벌어지는 일 | 결과 |
| --- | --- | --- | --- |
| **P1** | **무서운 순간이 예고 없이 온다** | 내비는 "300m 앞 우측 합류"까지만 알려 준다. *어느 차선에서, 언제 깜빡이를 켜고, 얼마나 속도를 올려야 하는지*는 알려 주지 않는다. | 그 순간에 얼어붙고, 다음부터 그 길을 피한다. |
| **P2** | **연수가 끝나면 혼자다** | 10시간 30~58만원 연수를 받아도, 끝난 다음 날부터 옆에 아무도 없다. 가족이 옆에 타면 싸움이 난다. | 연수 직후가 가장 위험한데, 그때 도움이 끊긴다. |
| **P3** | **늘고 있는지 모른다** | 운전 후 피드백이 없다. 잘한 건지 운이 좋았던 건지 모른다. | 자신감이 안 생겨 다시 운전을 안 하게 된다(장롱면허 재발). |

### 1.4 기존 수단의 한계

| 기존 수단 | 한계 |
| --- | --- |
| 도로연수(학원·방문) | 비싸고 시간이 정해져 있다. 끝나면 끝. |
| 시뮬레이터 앱 | 실제 도로·내 차가 아니다. |
| 내비게이션 | 길은 알려 주지만 *운전하는 법*은 알려 주지 않는다. |
| 운전점수 앱(티맵 등) | 운전이 끝난 뒤 급가속·급제동 점수. **미리** 알려 주지 않고, 초보의 무서운 순간을 구분하지 않는다. |

### 1.5 한 사람의 이야기 (지금)

**이수진(29)**은 대학 때 딴 면허가 7년째 장롱에 있다. 회사가 외곽으로 이사하면서 첫 차(아반떼)를 샀다. 방문연수 10시간을 받고 혼자 출근한 첫날, 순환도로 합류에서 속도를 못 올려 뒤차가 경적을 울렸다. 그 뒤로는 합류가 없는 길로 20분을 돌아간다. 연수를 더 받자니 돈이 아깝고, 남편이 옆에 타면 싸운다.

## 2. 해결 방향

### 2.1 한 줄 소개

> **보조바퀴 — 조수석에 앉은 보이지 않는 운전 강사.** 어려운 순간 직전에 말해 주고, 잘하면 칭찬하고, 실력이 늘수록 도움을 줄이다가, 만렙이 되면 **졸업시키고 물러난다.**
>
> 도로연수를 대체하지 않는다. **연수가 끝난 다음 날부터** 혼자 운전하는 시기를 맡는 "연수 다음 단계"다 (11.3).

### 2.2 문제별 해결

| 문제 | 해결 | 장치 |
| --- | --- | --- |
| P1 순간이 예고 없이 온다 | 내비 경로를 미리 읽어 **무서운 순간 1km·300m 전에** 구체적으로 말해 준다 | 미리 알려 주는 음성 코칭 (3.3) |
| P2 연수 후 혼자다 | 매 운전이 연수가 된다. **연습 경로**를 난이도별로 짜 준다 | 연습 경로 추천 (3.2) |
| P3 늘고 있는지 모른다 | 구간별 **채점**, 정복한 구간이 지도에서 바뀌고, **캐릭터가 레벨업** | 채점(4절), 레벨(5절), 졸업(6절) |

### 2.3 설계 원칙

1. **운전 전체가 아니라 순간 단위**로 코칭한다.
2. **사후 지적이 아니라 사전 안내.** 틀린 건 주행 중에 말하지 않는다.
3. **오래 쓰게 하는 게 아니라 빨리 졸업시키는 게 목표.**
4. **운전 중 화면은 쓰지 않는다.** 점수·레벨은 P단에서만.

## 3. 기능

### 3.1 첫 설정: "어디가 무서워요?"
- **언제**: 처음 켤 때(P단)
- **화면**: 그림 카드 8장 중 무서운 것 고르기 — 고속도로 합류 / 비보호 좌회전 / 차선 많은 교차로 / 좁은 골목 / 후진 주차 / 터널 / 야간 / 빗길
- **결과**: 나만의 **무서운 구간 지도** 생성. 처음엔 고른 항목이 🔴
- **연수 확인**: *"도로연수를 받았나요?"* 안 받았으면 연수를 먼저 안내한다(제휴 업체 연결). 받았으면 강사가 넘겨 준 구간을 지도에 반영한다 (11.3).

### 3.2 연습 경로 추천
- **언제**: 출발 전 "오늘 연습할래요"
- **화면**: 집 근처 경로 3개 — 🟢 *동네 한 바퀴 15분 · 좌회전 2번, 합류 없음* / 🟡 *대형마트 왕복 25분 · 합류 1번* / 🔴 *순환도로 한 구간 30분 · 합류 3번*
- **동작**: 고르면 내비 목적지·경유지로 자동 설정
- **신호**: NaviHelper `requestRoute`, `addWaypoint`

### 3.3 미리 알려 주는 음성 코칭 (핵심)
- **언제**: 주행 중, 사용자가 아직 정복하지 못한 구간 1km·300m 전
- **음성 예시**
  - 합류 1km 전: *"1km 뒤 고속도로 합류예요. 지금 오른쪽 끝 차선으로 미리 가 있어요."*
  - 합류 300m 전: *"합류 차선에서 속도를 충분히 올리고, 왼쪽 깜빡이 먼저 켜요."*
  - 비보호 좌회전 앞: *"여기는 신호가 없어요. 맞은편 차가 다 지나간 뒤에 천천히 돌아요."*
- **화면**: 내비 옆 창에 *"합류 준비 중"* 한 줄
- **신호**: NaviHelper `onTBTInfo`(회전 종류·남은 거리), 경로 정보

### 3.4 후진 주차 도우미
- **언제**: 기어가 R로 바뀔 때
- **음성**: *"천천히요. 핸들은 오른쪽 끝까지 돌린 상태에서 시작해요."* 후방 카메라 화면은 차량 기본 기능을 쓰고 앱은 음성만.
- **신호**: 기어(R), 속도

### 3.5 운전 후 복기 카드
- **언제**: 도착 후 P단
- **화면**: *"오늘 25분 · 82점 · 합류 ✅ · 좌회전 ✅ · 깜빡이 늦음 1번"* + 무서운 구간 지도 변화 + 캐릭터 경험치
- **다음 목표 하나**: *"좌회전 깜빡이만 조금 일찍 켜면 90점대예요."*

### 3.6 복귀 모드
- 졸업 후 **3개월 이상 운전 기록이 없으면** *"오랜만이에요. 동네 한 바퀴부터 다시 해 볼까요?"* → 🟢 연습 경로 한 번으로 감각 회복. 장롱면허 재발 방지.

## 4. 채점

### 4.1 구간 점수 (구간 하나를 지날 때마다)

| 구간 | 채점 항목 (초기안) | 신호 |
| --- | --- | --- |
| 고속도로 합류 | 깜빡이를 합류 지점 전에 켰나 · 합류 직후 속도가 충분했나 · 합류 직후 급제동 없음 | TurnSignal, 속도, Brake, TBT |
| 좌·우회전 | 회전 지점 50m 전 깜빡이 · 회전 중 급제동 없음 | TurnSignal, Brake, TBT |
| 차선 많은 교차로 | 회전 전 차선 변경 시 깜빡이 · 급제동 없음 | TurnSignal, Brake, TBT |
| 후진 주차 | R↔D 전환 횟수 · 완료까지 걸린 시간 | 기어, 속도 |
| 빗길·야간 | 평소보다 속도를 줄였나 · 급제동 없음 | Wiper, Light, 속도, Brake |

### 4.2 주행 점수
- 그날 지난 구간 점수의 평균(0~100). P단에서만 표시.
- **속도는 가점 요소가 아니다.** 빨리 갈수록 점수가 오르는 구조를 만들지 않는다.
- 임계값(50m, 급제동 기준 등)은 초기값이며 실차 데이터로 조정한다.

## 5. 캐릭터와 레벨

### 5.1 캐릭터: 타는 것이 진화한다

| 레벨 | 캐릭터가 타는 것 | 다음 레벨 조건 (초기안) |
| --- | --- | --- |
| Lv.1 | 🛴 세발자전거 | 첫 운전 완료 |
| Lv.2~3 | 🚲 보조바퀴 자전거 | 연습 경로 3회, 좌·우회전 🟢 |
| Lv.4~5 | 🚲 두발자전거 (보조바퀴 하나 떼기) | 차선 많은 교차로·후진 주차 🟢 |
| Lv.6~7 | 🛵 스쿠터 | 고속도로 합류 🟢, 최근 5회 평균 80점 이상 |
| Lv.8~9 | 🚗 자동차 | 야간·빗길 각 1회 이상 🟢 |
| **Lv.10 (만렙)** | 🎓 **졸업** | 무서운 구간 8개 모두 🟢 + 최근 5회 평균 85점 이상 |

### 5.2 보조바퀴 떼기 (구간별 코칭 단계)
- 같은 종류의 구간을 **3번 연속 80점 이상**으로 넘기면 그 구간의 코칭 단계를 낮춘다.
  - 1단계: 1km + 300m 전 두 번 안내 → 2단계: 300m 전 한 번 → 3단계: 안내 없음(지도에서 🟢)
- 음성: *"이제 합류는 혼자 해도 되겠어요. 다음부터는 안 알려 드릴게요."*
- 다시 점수가 떨어지면(2회 연속 60점 미만) 한 단계 되돌린다.

### 5.3 레벨 설계 원칙
- **많이 운전한다고 오르지 않는다.** 구간을 정복해야 오른다. 레벨 = 실제 실력.
- 연속 출석(streak)처럼 *운전을 더 하게 만드는* 장치는 넣지 않는다.

## 6. 만렙 = 졸업

1. 캐릭터가 차를 타고 떠나는 **졸업 장면** + *"이제 혼자 운전해도 돼요."*
2. **졸업장** 발급: 정복한 구간, 운전 기록 요약, 날짜. 가족 공유·보험 제출 가능.
3. **코칭이 완전히 꺼진다.** 앱은 조용히 남는다.
4. 3개월 공백이면 복귀 모드(3.6).

## 7. 게임 요소 안전 원칙

- 주행 중에는 점수·레벨·캐릭터를 띄우지 않는다(효과음 정도만). Pleos 운전 중 주의분산 가이드(게임 유도 금지, 화면 최소화)에 맞춘다.
- 속도·주행 시간·주행 거리로 점수나 경험치를 주지 않는다.
- 틀린 점은 주행 중에 말하지 않고 P단 복기에서만.

## 8. 차량 신호와 API

| 용도 | API | 상태 |
| --- | --- | --- |
| 다가오는 회전·합류와 남은 거리 | NaviHelper `onTBTInfo` | ✅ 이벤트 존재, **필드(회전 종류·합류 구분) 확인 필요** |
| 연습 경로 설정 | NaviHelper `requestRoute`, `addWaypoint`(최대 2곳), `RouteOption` | ✅ 문서 확인 |
| 깜빡이 타이밍 | Vehicle TurnSignal 리스너 | ✅ API 존재 |
| 급제동 | Vehicle Brake 리스너 + 속도(AAOS Car API) | ✅ API 존재 |
| 후진 주차 | 기어(AAOS `GEAR_SELECTION`) | ❓ 서드파티 수신 검증 필요 |
| 빗길·야간 | Vehicle Wiper, Light | ✅ API 존재 |
| 음성 코칭 | TextToSpeech, 오디오 포커스 정책(내비 안내와 겹치지 않게) | ✅ 문서 확인 |

**가장 큰 기술 리스크**: "합류"·"비보호 좌회전"을 TBT 정보로 구분할 수 있는지. 안 되면 회전 종류(좌·우·유턴)만으로 시작하고, 합류·비보호는 경로 좌표와 공공 도로 데이터로 보완한다.

## 9. 심사 기준 대응

| 기준 | 점수 | 근거 |
| --- | --- | --- |
| 차량특화성 | 5 | 내비 경로를 미리 읽고 깜빡이·기어·브레이크로 판정하는 순간 단위 코칭은 폰만으로 불가능. 주행 중(음성)·P단(점수·레벨)·R단(주차)에서 동작이 다르다. |

| 기술 활용성 | 5 | NaviHelper(경로·TBT·경유지), Vehicle(TurnSignal·Brake·Wiper·Light·기어), TTS가 모두 핵심 흐름. |

| 실현성 | 3~4 | TBT 필드로 합류·비보호를 구분할 수 있는지가 관건. 회전만으로도 핵심 시연은 가능. |

## 10. 사업성: "졸업하면 떠나잖아요?"에 대한 답

| 관점 | 답 |
| --- | --- |
| 핵심 지표 | MAU 대신 **연간 졸업생 수, 졸업률, 졸업까지 걸린 기간** |
| 들어오는 사람 | 매년 새 면허 취득자, 장롱면허자, 첫 차 구매자. 졸업하는 만큼 새로 들어온다 |
| 수익 | ① **졸업 패스**(1회 결제, 도로연수 10시간 30~58만원보다 훨씬 저렴) ② **보험 제휴**: 졸업장 = 초보 할인 인증. 초보 사고율이 2배라 보험사에 가치가 크다 ③ **첫 차 번들**: 2번째 Pleos 탑재 차종으로 거론되는 아반떼는 대표적 첫 차 ④ **연수 업체 제휴**: 연수 마지막 날 설치하는 사후 관리 상품, 졸업 못 한 구간의 추가 연수 연결 (11.3) |
| 남는 연결 | 복귀 모드, 가족 초대, 같은 엔진(본인 기준선 비교)으로 [DriveWatch](drive-watch.md)와 이어지는 *운전 생애 주기* 이야기 |

### 11.3 도로연수·시뮬레이터와 겹치지 않나? (심사 예상 질문)

**결론: 같은 고객을 보지만 단계가 다르다. 경쟁이 아니라 앞뒤로 이어지는 관계이고, 도로연수 업체는 파트너가 된다.**

#### 운전을 배우는 흐름

```
면허 취득 → [시뮬레이터 앱] → [도로연수 10시간] → [혼자 운전하는 첫 몇 달] → 익숙해짐
             가상 도로          강사가 옆에 탐        아무도 없음 ← 보조바퀴의 자리
```

| | 시뮬레이터 앱 (도로로 등) | 도로연수 (학원·방문) | **보조바퀴** |
| --- | --- | --- | --- |
| 언제 | 실제 도로에 나가기 전 | 처음 도로에 나갈 때 | **연수가 끝난 뒤** 혼자 운전할 때 |
| 어디서 | 폰 속 가상 도로 | 실제 도로, 강사 차 또는 내 차 | 실제 도로, **내 차, 내 출퇴근길** |
| 옆에 누가 | 없음 | 강사 (보조 브레이크로 개입 가능) | 음성 코치 (개입 불가) |
| 기간 | 수시로 | 10시간 안팎 | 졸업할 때까지 몇 주~몇 달 |
| 비용 | 무료~저렴 | 10시간 30~58만원 | 졸업 패스 (연수보다 저렴) |

문제 정의의 **P2 "연수가 끝나면 혼자다"**가 이 빈자리다. 연수는 10시간이 끝나면 끝이고, 시뮬레이터는 실제 도로가 아니다. *내 차로 내 생활 도로를 혼자 다니는 시기*는 지금 아무도 돕지 않는다.

#### 솔직하게 겹치는 부분
- **메시지**: "장롱면허 탈출"이라는 문구는 같다. 마케팅만 보면 비슷해 보인다.
- **예산**: 연수를 20시간 받을 사람이 10시간만 받고 넘어올 수 있다.

#### 포지셔닝 원칙
- **"도로연수 다음 단계"**로 말한다. 연수에서 배운 것을 혼자 운전할 때 끝까지 이어 준다.
- **도로연수를 대체한다고 말하지 않는다.** 강사는 보조 브레이크로 개입할 수 있지만 이 앱은 말만 할 수 있다. 대체를 주장하면 안전 문제로 바로 반박된다.
- 처음 도로에 나가는 사람에게는 **연수를 먼저 권한다.** 첫 설정에서 "도로연수를 받았나요?"를 묻고, 안 받았으면 연수를 안내한다.

#### 도로연수 업체를 파트너로
| 제휴 방식 | 연수 업체가 얻는 것 | 보조바퀴가 얻는 것 |
| --- | --- | --- |
| 연수 마지막 날 강사가 보조바퀴를 켜 주고, 학생이 어려워한 구간을 무서운 구간 지도에 미리 넣어 준다 | "연수 후 사후 관리"라는 추가 상품, 차별화 | 사용자 유입 채널, 정확한 초기 지도 |
| 졸업 못 한 구간이 오래 남으면 *"이 구간은 강사와 1시간 더 연습해 볼까요?"*로 연수 업체를 연결한다 | 추가 수강 | 안전한 해결책 제시, 중개 수익 |

경찰청이 2025-12 "학원 밖, 원하는 장소에서의 연수"를 허용하는 방향으로 법령 개정을 밝혔다. 연수가 내 생활 도로로 나오면, **연수 후에도 그 길을 계속 코칭하는 것**이 자연스러운 다음 단계가 된다.

#### 진짜 경쟁 상대
시뮬레이터나 도로연수가 아니라 **Honda Driver Coaching 같은 "실제 도로 코칭 앱"**이다. 차이는 11.2 표에서 정리했다.

### 11.4 시사점
- 자동차 회사(Honda)가 직접 초보 코칭 앱을 냈다 → **완성차 입장에서 의미 있는 영역**이라는 근거. 현대차 심사위원에게도 설득력 있다.
- 다만 "운전 코칭 앱"만으로는 새롭지 않다. 기획서는 **사전 안내, 순간 단위 정복, 졸업**을 전면에 둔다.
- 도로연수와는 **경쟁이 아니라 연결**. "연수 다음 단계"로 포지셔닝하고 연수 업체를 유입 채널로 삼는다.

## 12. 시연 시나리오 (약 90초)

1. 첫 설정: 무서운 구간으로 "고속도로 합류", "후진 주차" 선택 → 지도에 🔴 2개.
2. 연습 경로 🟡 선택 → 내비에 목적지·경유지 자동 설정.
3. 주행: 합류 1km 전 음성 → 300m 전 음성 → Virtual Console에서 왼쪽 깜빡이 ON → 통과 후 *"합류 깔끔했어요!"*
4. 도착 P단: 복기 카드 *"88점"*, 합류 🔴→🟡, 캐릭터 경험치 상승.
5. (빨리 감기) 합류 3회 연속 통과 → *"이제 합류는 혼자 해도 되겠어요"* → 🟢, 캐릭터가 두발자전거로 진화.
6. (빨리 감기) 만렙 → 졸업 장면과 졸업장.

## 13. 리스크와 확인할 것

- **도로연수 대체로 오해**: "연수 안 받아도 된다"로 읽히면 안전 문제로 반박된다 → "연수 다음 단계" 포지셔닝, 첫 설정에서 연수 이수 여부 확인 (11.3).
- **TBT 필드**: 합류·비보호 좌회전을 구분할 수 있는지 SDK에서 확인.
- **정확한 판정의 한계**: 차선 위치·주변 차량은 알 수 없다(카메라·ADAS 데이터 없음). 채점은 깜빡이·속도·제동처럼 **알 수 있는 것만** 한다고 명시.
- **책임 문제**: 코칭을 따르다 사고가 나면? → "운전 판단은 운전자에게" 고지, 안내는 일반적 운전 요령 수준으로 제한.
- **음성 겹침**: 내비 안내 음성과 코칭이 겹치지 않도록 오디오 포커스 처리.
- **장롱면허 규모**: 공식 통계 확보 필요.
- **Honda 앱과의 비교 질문**: 11.2 표로 대비.

## 14. 다음 단계

1. 에뮬레이터: `onTBTInfo` 실제 필드, TurnSignal·Brake 리스너, 기어 이벤트 확인.
2. 인터뷰: 장롱면허자·첫 차 구매자 3~5명 — 가장 무서운 순간, 연수 후 경험.
3. 통계: 장롱면허 규모, 초보 사고율 최신 자료.
4. 화면 시안: 첫 설정, 주행 중 코칭, 복기 카드, 레벨업, 졸업 장면.
5. 팀 결정: DriveWatch와 비교해 최종 방향 확정(두 앱을 *운전 생애 주기*로 묶는 안도 검토).

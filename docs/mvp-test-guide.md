# DriveWatch MVP 테스트 가이드

작성 winter1 · 2026-11-11 · 고침 2026-11-12(초대 QR·문자, 시연 재생, 시계 차, 가족에게 부탁, 업데이트 알림)

Pleos Connect Emulator에서 차량 앱을 처음부터 끝까지 확인하는 순서다. 시연 영상도 이 순서로 찍는다.

**가짜와 진짜.** 기어 · 방향지시등 · 브레이크 · 차속은 에뮬레이터의 차량 신호로 실제로 받는다. 가족 서버(초대 · 연결 · 요약 · 확인 · 가족에게 부탁)도 실제로 돈다. 내비 안내(회전 안내 · 재탐색), 과거 기록, 시연 재생, 대리운전 연결은 시연용이다. 화면에도 "시연용"이라고 표시한다.

---

## 1. 준비 (처음 한 번)

1. **에뮬레이터 설치.** [Pleos 공식 가이드](https://document.pleos.ai/docs/connect/guide/getting-started/application-development/setup-connect-sdk-emulator)를 따른다.
   - SDK Manager → SDK Update Sites에 맥용 주소(`crp-arm64-sys-img.xml`)를 추가한다.
   - SDK Platforms의 API 34에서 Pleos Connect system Image를 설치한다. Show Package Details를 켜야 보인다.
   - **Android Studio를 재시작한다.** 재시작해야 기기 목록에 Pleos가 나온다.
   - Device Manager → Automotive → Pleos Connect v2.1.0. Cold boot, RAM 4 GB로 만든다.
2. **에뮬레이터를 켠다.** Device Manager에서 ▶를 누른다.
3. **기본 주행 화면 앱을 끈다.**
   - 이 에뮬레이터는 `ai.umos.drivingview`가 그래픽 오류로 20초마다 죽는다. 죽을 때마다 화면을 가져가서 테스트를 방해한다.
   - 에뮬레이터 안에서만 바뀌는 설정이다. 되돌릴 때는 `disable-user`를 `enable`로 바꿔 실행한다.

   ```bash
   adb shell pm disable-user --user 10 ai.umos.drivingview
   ```

4. **앱을 빌드하고 설치한다.** `-g`는 차량 권한을 미리 허용한다.

   ```bash
   ./gradlew :app:assembleDebug
   ```

   ```bash
   adb install -r -g app/build/outputs/apk/debug/app-debug.apk
   ```

5. 하단 작업표시줄에 생긴 **보라색 시계 차 아이콘(DriveWatch)**을 누른다. 앱은 오른쪽 큰 영역에 뜬다. 아이콘이 예전 그림이면 런처가 캐시한 것이다. 에뮬레이터를 다시 켜면 바뀐다.

   팀 공용 키로 서명한 APK(`assembleRelease`)가 이미 깔려 있으면 디버그 APK는 덮어 설치되지 않는다(`INSTALL_FAILED_UPDATE_INCOMPATIBLE`). 한 번 지우고 설치하거나 `assembleRelease`로 빌드한다.

## 2. 주행시키는 방법

앱에서 목적지를 누르면 **"기어를 D로 넣으면 안내를 시작해요"**가 뜬다. 이 상태에서 아래 넷 중 하나로 차를 움직인다. **목적지를 누르기 전에 차를 움직이면 기록되지 않는다.**

| 방법 | 어떻게 | 언제 |
| --- | --- | --- |
| **앱 버튼 (추천)** | 그 화면의 `시연 주행 시작 (Virtual Console)`을 누른다 | 대부분 이걸로 한다. 고른 길(빠른 길 / 편한 길)에 맞는 주행을 자동으로 한다 |
| 시연 재생 | 그 화면의 `시연 재생 (서버 시나리오)`를 누른다 | Virtual Console 없이 앱 안에서 기록된 주행을 재생한다. 시나리오는 가족 서버(`/api/demo/drives/…`)에서 받고, 못 받으면 앱에 담긴 예비본을 쓴다. 실제 차속이 들어오면 재생을 멈춘다 |
| 터미널 스크립트 | `adb forward tcp:8088 tcp:8088` 후 `python3 tools/demo-drive.py`. 편한 길이면 끝에 `comfortable`을 붙인다 | 앱 버튼과 같은 주행이다. 앱 밖에서 돌리고 싶을 때 쓴다 |
| 손으로 | 브라우저에서 `http://127.0.0.1:8088/`(Virtual Console)을 열고 기어 Drive → … → Park | 원하는 대로 운전해 볼 때 쓴다. 회전 안내 시각(D 기준 2·5·15초)에 맞춰 깜빡이를 켜야 "켬"으로 센다 |

주행은 빠른 길 약 25초, 편한 길 약 21초 걸린다. **D가 되면 Pleos가 내비를 화면 앞으로 가져온다.** 앱은 뒤에서 계속 기록하고 음성으로 말한다. P가 되면 작업표시줄 아이콘으로 앱을 다시 연다.

빠른 길 시연 주행에서 나와야 하는 값:

| 회전 안내 | 깜빡이 | 재탐색 | 급제동 |
| --- | --- | --- | --- |
| 3번 | 2번 (5초 좌회전은 안 켬) | 2번 (중앙대로 합류) | 1번 (12초쯤) |

## 3. 시연 순서와 확인할 것

| # | 조작 | 확인할 것 |
| --- | --- | --- |
| 1 | 운전자 등록(이름 `김정숙`) → `다음` | 동의 화면이 나온다. 김정숙은 시연용 과거 기록 12주를 갖고 시작한다 |
| 2 | 동의 화면에서 `읽어 주기` → `동의하고 시작` | Pleos 음성으로 읽는다. 약속 화면으로 넘어간다 |
| 3 | 약속 2개 켜진 채 `다음 · 가족 연결` | QR과 6자리 초대 코드(가족 서버에서 받음), `코드 읽어 주기`, 자녀 번호 칸과 `연락처`, 문자 동의 체크가 나온다 |
| 4 | (자녀 연결은 5절) `나중에 연결` | 홈 화면, 상태 칩 "안정 · 12주째 기록"과 시계 차 배지(바늘이 초록 칸) |
| 5 | `병원` → `시연 주행 시작` | 주행 중 재탐색 두 번째에 음성 "천천히 가셔도 괜찮아요…" |
| 6 | 주행이 끝나면 앱을 연다 | "병원에 도착했어요 (P)", 2절 표의 값, 음성 한 줄, "중앙대로 합류 … 표시해 둘까요?" |
| 7 | `표시하기` → `홈으로` | 병원 카드에 "표시한 구간 있음" |
| 8 | 상단 `시연 패널 ▾` → `다음 주로` → `병원` | 빠른 길 24분 / 편한 길 28분 비교 화면 |
| 9 | `편한 길` → `시연 주행 시작` | 도착 후 "재탐색 0번", 깜빡이 3번 다 켬, 칭찬 음성 |
| 10 | 시연 패널 `밤 9시로` → 홈 | 화면이 밤 테마로 바뀌고 음성 "오늘은 늦었네요…", `다른 방법으로 가기` → `대리운전`(시연용) / `가족에게 부탁`. 부탁하면 "보냈어요 · … 님의 답을 기다려요", 가족이 답하면 "… 님이 태우러 와요"(5절) |
| 11 | `낮으로` → `4주 뒤로` → `이번 주 카드` | 상태 "대화 권장", 시계 차의 바늘이 주황 칸·걱정하는 얼굴, 근거 "평소 0.2 → 이번 주 1.0회/10km · 4주 연속" |
| 12 | 상단 프로필 `박영호` | 기록이 따로이고 상태는 "안정". 시연 패널 `기록:` 버튼을 누를 때마다 평소대로 → 관찰 → 대화 권장 시나리오로 바뀐다 |
| 13 | `+ 운전자 추가` | 새 운전자 등록. 동의 화면에 "어르신 팩" 표시. 새 운전자는 "학습 중 · 0/12주" |
| 14 | 홈 `월별 기록` | 이번 달 주별 상태·주행·지표, 오른쪽에 "지금 운전 상태"와 다음에 해 볼 것. ◀ ▶로 달을 바꾼다 |
| 15 | 월별 기록 아래 `운전 졸업 안내` | 반납 방법, 자주 가던 곳마다 `가족에게 부탁`(실제로 가족 폰에 감), "차와 이동은 이렇게 이어져요"(인증중고차·셔클, 제휴 예정) |
| 16 | (가족 연결 후) 시연 패널 `최근 4주 요약 보내기` → 폰 `월별 기록 보기` | 폰에 달별 흐름(예: 대화 권장 → 안정 → 관찰)과 주별 요약이 보인다 |

처음부터 다시 하려면 시연 패널의 `처음부터`를 누른다. 운전자 목록, 서버 연결, 동의, 약속은 차에 저장돼 앱을 다시 켜도 남는다. 주행 기록과 표시한 구간은 운전자가 서버 보관을 허락했을 때만 다시 켠 뒤에도 남는다(5-1절).

## 4. 음성

- Pleos TextToSpeech SDK(기기 내 모드)로 말한다. 소리는 맥 스피커로 나온다.
- 일반 Android 에뮬레이터에서는 기본 TTS로 대신 말한다.
- 소리가 안 나면 맥 음량과 에뮬레이터 음량을 확인한다.

## 5. 자녀 폰 연결 (가족 요약)

1. 차 앱의 가족 연결 화면(온보딩 마지막, 또는 홈의 `가족 초대하기`)에 QR과 6자리 코드가 뜬다. 코드는 10분 동안 유효하다. 넘기는 방법은 넷이다.
   - **QR**: 자녀 폰 카메라로 찍으면 코드가 채워진 폰 화면이 열린다.
   - **코드**: 폰 브라우저에서 `drive.olvend.com/family`를 열고 넣는다. `코드 읽어 주기`는 음성으로 읽는다.
   - **문자**: 자녀 번호를 넣거나 `연락처`에서 고르고, 수집 동의를 체크한 뒤 보낸다. 서버에 문자 키가 없으면 시연 모드로 답하고 실제로는 보내지 않는다. 번호는 저장하지 않는다.
   - **부모님 폰으로 찍었을 때**: 폰 화면이 "누가 열었나요?"를 묻는다. `제가 운전하는 사람이에요`를 고르면 자녀에게 링크를 보내는 화면이 나온다(문자 앱 `sms:`·공유·복사). 동의하고 번호를 넣었으면 QR 주소의 `#to=` 뒤에 번호가 담겨 받는 사람이 미리 채워진다. `#` 뒤는 서버로 가지 않는다.
2. 폰 없이 시연할 때는 `시연용 · 가상 자녀(김민수)로 연결하기`를 누른다.
3. 차 화면이 "… 님과 연결됐어요"로 바뀐다. 4초마다 새로 확인한다.
4. 3절 11번의 이번 주 카드에서 `가족에게 보내기`를 누른다. 버튼이 보내는 중 → 보냈어요로 바뀐다.
5. 폰에서 요약을 열고 `확인했어요`를 누른다. 차 홈의 가족 카드에 확인 표시가 뜬다. 폰의 목록·요약·월별 기록에도 같은 시계 차 배지가 붙는다.
6. **가족에게 부탁**: 3절 10번이나 15번에서 `가족에게 부탁`을 누르면 폰 목록 맨 위에 "엄마가 병원 가는 길에 도움을 부탁했어요" 카드가 뜬다. `제가 태우러 갈게요` 또는 `택시를 불러 드릴게요`를 누르면 4초 안에 차 화면에 답이 나온다. 부탁은 12시간 동안 보이고, 먼저 답한 가족이 맡는다.

동의 화면에서 `상태만`을 골랐으면 폰에는 숫자 근거가 보이지 않는다. 이게 정상이다.

## 5-1. 주행 기록 서버 보관

- 동의 화면 다음에 **"주행 기록을 서버에 보관할까요?"** 안내창이 뜬다. `보관하기`를 고르면 주행이 끝날 때마다 횟수 요약이 가족 서버에 올라가고, 표시한 구간과 약속도 같이 보관된다. `차에만 두기`를 고르면 아무것도 올리지 않는다.
- 확인: 주행 → 앱을 완전히 껐다 켠다(`adb shell am force-stop com.parkhere.drivewatch`) → 운전자, 표시한 구간, 이번 주 기록이 그대로 있다.
- 끄기: `이번 주 운전`(운전 기록 화면) 아래의 `보관 끄고 서버 기록 지우기`. 누르면 서버에서 바로 지운다. `처음부터`도 서버 기록을 지운다.
- **로컬 서버로 테스트:** 공개 서버에 데이터를 남기지 않고 확인하려면 로컬 가족 서버를 띄운다.

  ```bash
  cd family-server && PORT=8795 node server.js
  ```

  ```bash
  ./gradlew :app:assembleDebug -PfamilyServer=http://10.0.2.2:8795
  ```

  `10.0.2.2`는 에뮬레이터에서 본 이 맥이다. 옵션 없이 빌드하면 `drive.olvend.com`을 쓴다.
- 시연 패널로 옮긴 시간(다음 주로, 4주 뒤로)의 합성 기록은 보관하지 않는다. 다시 켜면 시연용 과거 기록은 새로 만든다.

## 5-2. 새 버전 알림

- 앱은 켜질 때 가족 서버의 `/api/app/latest`를 보고, 자기보다 새 버전이 있으면 상단에 `새 버전` 칩을 띄운다. 누르면 바뀐 점과 내려받기 QR이 나온다. 차 안에서 스스로 설치하지는 않는다.
- 지금 버전은 시연 패널 아래에 `v0.2.0+<커밋> (versionCode)`로 보인다.

## 6. 자주 막히는 곳

| 증상 | 원인과 해결 |
| --- | --- |
| 앱 위에 **"주행 중에는 사용할 수 없습니다"** | 차가 D에 멈춰 있다(시연 주행 중에 앱을 다시 설치하거나 끄면 생긴다). `adb forward tcp:8088 tcp:8088` 후 `python3 tools/demo-drive.py park` |
| 연락처 버튼이 안 보임 | 연락처 앱이 없는 환경이다. 번호를 직접 넣는다 |
| 설치가 `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 서명 키가 다른 APK가 깔려 있다. 1절 5번 참고 |
| "기어를 D로 넣으면…"에서 멈춤 | 차가 아직 P다. `시연 주행 시작`을 누르거나 2절의 다른 방법으로 D를 넣는다 |
| 스크립트를 돌렸는데 기록이 없음 | 목적지를 먼저 누르지 않았다. 앱에서 목적지를 누른 뒤 돌린다 |
| 앱이 안 보이고 내비만 보임 | D일 때는 정상이다. P가 된 뒤 작업표시줄의 DriveWatch 아이콘을 누른다 |
| 앱을 열어도 20초마다 다른 화면이 뜸 | 1절 3번(주행 화면 앱 끄기)을 안 했다 |
| 오른쪽 깜빡이를 켜면 카메라 화면이 뜸 | Pleos의 사각지대 카메라다. 정상 동작이고, 깜빡이를 끄면 닫힌다 |
| 상단에 "차량 신호 없음 · 시연 주행" | 일반 Android 에뮬레이터다. 차량 신호 없이 시연 주행이 혼자 돈다 |
| 편한 길 화면이 안 나옴 | 그 목적지에 표시한 구간이 없다. 먼저 빠른 길로 다녀와서 `표시하기`를 누른다 |

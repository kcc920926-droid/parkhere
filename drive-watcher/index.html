DRIVEWATCH

부모님 운전에 차는 스마트워치

차량 신호로 부모님 운전을 나이가 아니라 본인의 평소와 비교해요. 달라진 구간을 주차 후에 보여 주고, 가족에게는 감시가 아닌 요약을 보내는 Pleos 차량 앱이에요.

판단 엔진 시연 Pleos 화면 바로 보기

이 페이지와 시연은 브라우저에서 돌아요. Android 차량 앱은 개발 중이고, 신호 수집과 판정은 Pleos 에뮬레이터에서 확인했어요.

01 / 9초 개요

한 번의 이동에서 일어나는 일

달리는 동안에는 조용히 기록만 해요. 같은 신호가 평소 범위를 두 구간 연속 넘었을 때만 변화로 남기고, 주차한 뒤에 보여 줘요.

D

도심 시연 기록을 재생해요

주차 후 · 차량 화면

합성한 도심 시연 기록을 실제 판정 엔진에 넣은 결과예요. 구간 길이와 기준값은 시연용이에요.

02 / 판단 엔진

입력이 바뀌면 판정이 바뀌어요

같은 코스를 자동 재생하거나 직접 운전해 보세요. 한 구간만 평소를 넘긴 기록과 두 구간 연속 넘긴 기록이 다르게 판정돼요. 공개 실측 CAN 기록으로도 같은 규칙을 돌려 볼 수 있어요.

구현 판단 엔진 시연 열기 자동 재생이 기본이고, 키보드로 직접 운전할 수도 있어요

03 / 차량 화면

주차하면 카드가 떠요

내비로 달리고, 주차한 뒤에 어느 구간이 달랐는지 확인해요. 분할 화면에서도 보던 내용이 이어지고, 이번 주 카드에서 변화가 돌아왔는지 이어졌는지 봐요.

구현 Pleos 화면 시연 열기 주차하기 → 드라이브 와쳐 → 어느 구간이었나요?

04 / 가족 요약

부모님이 먼저 보고, 보내기로 한 것만 가요

초대 코드는 부모님이 차에서 띄워요. "상태만"을 고르면 숫자는 차 밖으로 나가지 않고, 위치와 경로는 아예 보내지 않아요. 가족은 휴대폰 브라우저에서 요약을 봐요.

구현 가족 폰 화면 열기 가입 → 코드로 연결 → 주간 요약 구현 REST API 명세 차량 앱과 폰 화면이 쓰는 주소 10개

차량 앱에서 코드를 띄우고 요약을 보내는 화면은 개발 중이에요.

DriveWatch 가족 요약 API

연결 순서인증주소 목록 요약 형식오류 코드직접 불러 보기 OpenAPI 원본폰 화면

연결 순서

  1. 차량 앱이 운전자를 등록하고 carToken을 받는다. POST /api/car/drivers
  2. 운전자가 차에서 초대 코드를 띄운다. POST /api/car/invites
  3. 가족이 폰 화면에서 가입하고 코드를 넣는다. POST /api/family/members → POST /api/family/links
  4. 부모님이 주간 카드에서 보내기를 누르면 차량 앱이 요약을 보낸다. POST /api/car/summaries
  5. 폰 화면이 요약을 읽고 확인을 표시한다. GET …/summary → POST …/ack
  6. 차량 앱이 가족의 확인 여부를 읽는다. GET /api/car/me

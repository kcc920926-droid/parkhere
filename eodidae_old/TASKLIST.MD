# 어디대? 태스크리스트

[플레이북](PLAYBOOK.MD) 기준으로 검증과 구현 순서를 관리한다.

## P0 · 시연에 필요한 검증과 구현

- [ ] **E01 · 시연 시설 고르기** — 공항 또는 현장 검증이 쉬운 시설 한 곳을 고른다. 완료 기준은 실제 목적지 한 곳, 진입 가능한 주차장 입구 두 곳, 구역명, 걷거나 셔틀을 타는 기준점의 출처를 기록하는 것이다.
- [ ] **E02 · 기어 이벤트 검증** — Virtual Console에서 D→P→R→D를 바꾸고 앱의 이벤트 로그를 확인한다. 앱 전면, 내비 전면, 앱 복귀 각각에서 수신 여부와 권한 오류를 남긴다. 수신이 막히면 수동 확인 동선을 시연 범위에 반영한다.
- [ ] **E03 · 내비 연동** — 두 주차장 입구를 각각 설정하고 경로 설정·실패·도착 이벤트를 확인한다. 도착 이벤트가 없으면 주차 중 앱에서 현재 주차장 후보를 확인할 수 있게 한다.
- [ ] **E04 · 주차 후보 카드** — 안내와 도착 맥락이 있는 방문에서 P단 전환 시 초안 한 장을 띄운다. 확인, 다른 주차장 선택, 층·기둥 선택 입력, 주행 재개, 중복 이벤트, 앱 복귀를 검증한다.
- [ ] **E05 · 폰 연결과 재조회** — 출발 전 폰을 연결한 뒤 확정 위치를 보낸다. 차가 꺼진 상태에서 실제 폰으로 조회하고, 한 번 받은 카드는 폰이 오프라인이어도 확인한다. 초기 전송이 실패하면 차량에 재시도 대기를 표시한다.
- [ ] **E06 · 안내와 확정 상태 구분** — 미확정이면 마지막 안내 후보와 확인 여부만 표시한다. 확인된 주차장·층·기둥의 범위에 맞춰 카드와 지도 마커를 표시하고, 이전 확정 위치가 임시 정차로 덮어써지지 않는지 확인한다.
- [ ] **E07 · 시연 영상과 기획서** — P1을 안내받고 다른 구역에 세운 뒤, 폰에서 실제 확인한 구역을 찾는 왕복 장면을 촬영한다. 시설 데이터와 차량 이벤트에서 검증된 부분과 시연용 데이터를 구분해 표기한다. 1차 접수는 2026년 11월 15일까지이며 프로토타입 영상은 선택 가산점 항목이다. [공모전 참가 공고](https://appdevchallenge.auto-hmg.io/notice/c0a1a000-2026-4923-8000-000000000001)

## P1 · 기획서 근거와 사용성

- [ ] **E08 · 왕복 동선 비교** — 같은 목적지로 두 주차장에서 걸어보고, 입구부터 접수창구까지의 시간과 복귀 시 찾기 어려웠던 표지를 기록한다.
- [ ] **E09 · 사용자 테스트** — 운전자에게 위치 확인을 한 번만 요청하고, 다음 날 폰 카드로 구역과 복귀 기준점을 찾게 한다. 잘못된 층 선택, 확인 누락, 표지 혼동을 관찰한다.
- [ ] **E10 · 시설 데이터 약 10개 조합** — 목적지–추천 구역–실제 표지–도보 기준점 조합을 만든다. 데이터 출처와 마지막 검증일을 붙인다.
- [ ] **E11 · 브랜드 적용** — [브랜드 시안](docs/brand/brand-preview.svg)의 회색·노란색·파란색을 차량과 폰 화면에 적용한다. 마커를 작은 크기로 봐도 구역명과 내 차 표시가 읽히는지 확인한다.
- [ ] **E12 · 위치 데이터 관리** — 연결된 폰만 카드를 볼 수 있도록 접근 범위를 설계하고, 주차 기록의 삭제·연결 해제·보관 기간을 정한다.

## P2 · 데이터 연결 후 검토

- [ ] **E13 · 항공편과 주차장 데이터** — 항공편 번호·날짜로 터미널 확인, 주차장별 혼잡도와 갱신 주기 확인, 데이터 누락 시 후보 표시 기준을 검증한다.
- [ ] **E14 · 만차 시 대체 입구 안내** — 주차장 단위 데이터가 검증되면 대체 후보를 보여주고, 운전자 선택 후 내비 경로 변경을 확인한다.
- [ ] **E15 · 실내·시설 동선 확장** — 시설 도면에 기둥과 도보 기준점을 연결한다. 지도 연결이 있는 시설부터 층 이동과 보행 경로를 안내한다.
- [ ] **E16 · Gleo와 대기열 실험** — 목적지·주차 조건을 받는 음성 호출을 확인한다. 입구 대기열은 데이터 접근이 가능한 시설 한 곳에서 차량 수와 실제 대기 시간의 관계를 확인한다.
- [ ] **E17 · 시설 제휴 검증** — 운영사에 안내 데이터 유지 담당자, 안내 문의 유형, 운영 효과를 확인할 지표를 묻는다.
